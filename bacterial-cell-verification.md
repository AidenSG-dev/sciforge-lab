# Bacterial Cell verification

The Biology → 3D Cell Explorer route was verified with the existing Animal cell selection before testing the new state. Selecting the existing `Bacterial cell` option changes the viewport to the official Sketchfab embed:

`https://sketchfab.com/models/42439edc90cd4d87b8ae322a4dcee8de/embed`

The iframe fills the same responsive designated viewport and displays the Bacterial cell structure model by Ebers. The explicit attribution link points to the canonical Sketchfab model page:

`https://sketchfab.com/3d-models/bacterial-cell-structure-42439edc90cd4d87b8ae322a4dcee8de`

Animal Cell and Plant Cell mappings remain unchanged. TypeScript, production build, and lint pass with only the existing six Fast Refresh warnings.
